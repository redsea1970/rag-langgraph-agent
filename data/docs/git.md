# Git: основы

## Инициализация
Создать новый репозиторий: git init. Клонировать: git clone <url>.

## Коммиты
Добавить файлы: git add . Создать коммит: git commit -m "message".

## Ветки
Создать ветку: git branch <name>. Переключиться: git checkout <name>.

## Слияние
Слить ветку: git merge <name>. Разрешить конфликты вручную.

## Удалённые репозитории
Добавить remote: git remote add origin <url>. Отправить: git push -u origin main.
